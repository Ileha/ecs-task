# EcsTask Analyzers

LEOECS103 (awaited call without the cancellation token) and LEOECS105 (EcsTask not awaited).
They need only `EcsTask`, so they also run in assemblies without ECS.

Docs, examples, build and test commands for all LEOECS 1xx rules:
`Packages/ecs-async-system/Analyzers~/README.md`.
